About this restoration stage

This pre-rewrite scene combines preserved Core terrain and character assets with the recovered newer UserMovement controller and inventory rules. Original jump physics and movement smoothing are retained; this controller has no Shift walk command or object collisions. The browser camera, local item store and UI are adapters. All35loot icons are original artwork; Add Automag is a recovery fixture. All11ranged weapons use original slot rules, models, poses and hand attachments; item transactions and UI run locally. Both original body rigs are available. Sky / character view shows the original default-noon sky and two moving cloud layers. Original material maps, ambient fog and directional sunlight are restored. The original vital strip uses its recovered artwork and bar rules; click it to toggle numbers. Create or load a character to initialize stamina and energy. Object collisions, sound, shadows, point lights and the rest of the original UI remain work. The player Death button is an animation preview. This is progress toward the playable edition. The Jorgalosk circles until attacked, then turns, pursues and retaliates using its recovered brain and attack rules. Player death teleports to the LifeStone and revives at 75% health. Scene placement, default player stats and local event delivery are recovery adapters.
